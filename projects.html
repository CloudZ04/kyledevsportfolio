Action Against Stalking Website

Full Website Redesign & Development

2024-2025

  • A WordPress Elementor website that was re-designed for a modern look and feel.
  • Built using WordPress and Elementor, with some custom CSS & JavaScript.
  • Responsive design for both desktop and mobile devices.

While in college & university I had the opportunity to work on a client project for Action Against Stalking (AAS), where I contributed to design, development, and content structure with another student.

The CEO (our client) felt the original website was outdated, and was in need of updating. We decided the colour scheme to match the brand theme of the charity based on their logo, and created a new website that was more modern and user-friendly, while portraying the charity's values and mission.

I was also responsible for the design of a brand new logo for the 'Centre for Action Against Stalking' which I designed using Adobe Illustrator, taking inspiration from the charity's main logo, and values.

Jack's Pet Services

Website Design & Development

2026

  • Simple website design for a small pet service.
  • Built using WordPress and Elementor.
  • Responsive design for both desktop and mobile devices.

I worked with a small pet service, Jack's Pet Services, to create a simple and effective online presence. They were previously relying on Facebook and Instagram, so the goal was to give them a dedicated website to showcase their services in a more professional manner, while still being easy to navigate and use.

The focus was clarity and usability. I designed and built a clean, minimalist site using WordPress and Elementor, making sure it worked smoothly across both desktop and mobile devices. As the project didn't require complex functionality, I concentrated on a strong layout, clear content structure, and a user-friendly experience.

The website was designed and delivered within the week, reflecting the straightforward scope and the client's need for a quick, professional online presence.

GameTracker

Final Grade Project for NCL

2025

  • Built a personal game tracking site
  • Technologies: HTML, CSS, JavaScript, PHP & MySQL
  • Features: API integration, manual database editing, friends and messaging system

GameTracker.gg was just a personal project that I created to track upcoming games that had already, or been scheduled to release within the 2025-2026 period. Although now I have re-developed the site to hold many more games going back as far as 30 years ago as I wanted to use the site as a personal collection.

A lot of gamers, myself included, juggle a long list of titles they're playing, want to play, or want to revisit. GameTracker.gg was built to solve that for both my own collection and the wider gaming community. The project went on to earn me an A for my HND.

The site uses API integration and a PHP and MySQL based back-end for manual database editing. This includes fetching data, searching, manual insertion, deletion, and editing of data. The site also has a friends and messaging system now as I wanted to try build something new. As of now, the site is not live on the internet or the public as currently it is an on-going project I have recently started working on and polishing again. Requests to view the site on a temporary live server can be made by contacting me - although this will be the version I submitted for my HND.
